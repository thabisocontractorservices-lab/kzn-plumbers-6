# Code-first release — 8 September 2026

Baseline: release/kzn-growth-rebuild at 08cc3e65231b71154d6f9ba803d29485e8ecfb8f in thabisocontractorservices-lab/kzn-plumbers-6.

## User-facing changes

- Replaced the old admin panel with Overview, Listings, Ownership claims, Reviews & history, Bookings, Accounts, and Policies & reporting.
- Publication and claim actions use server-checked administrator identity plus existing admin role, confirmation dialogs, narrow conditional writes and explicit errors.
- Latest signed-in reviewer/business feedback is displayed as current. All older database rows remain intact and can be exported privately; no automatic five-row archive or unique index is applied.
- Added public review-concern links and contact-form context. Reports are delivered through existing mail configuration, not a fictitious dashboard ticket table.
- Fixed confirmed-email signup/claim return flows, anonymous booking persistence, owner/private certificate access, partial uploads and missing metrics.
- Preserved and tightened the KZN rebuild, public contact links, searchable collections, stable sorting/pagination/history, credential evidence and dated availability handling.
- Avoids automatic completeness-based noindex of historical profiles and generates complete, dated, failure-aware sitemaps.
- Existing owner booking/availability tools now use explicit owner checks and do not display missing storage fields as successfully saved data.

## Compatibility

No additional hosted project, Docker setup, user-run tests or database migration is part of this release. The existing schema is the baseline. Missing optional credential, lead or structured outcome columns show explicit capability notices. Essential configuration or table errors are not silently converted into success.

No live database, Storage, mail, credentials, RLS rules or API settings were changed during implementation. Existing database-level security risks are not repaired by first-party API changes. Credential and profile public-access observations remain visible in admin; see GO-LIVE-2026-09-08.md for limitations.
