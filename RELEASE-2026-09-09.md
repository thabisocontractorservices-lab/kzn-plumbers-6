# Claimed-first, location-scoped directory update

Baseline: production main at 0eaa70dbe89ee47516216ff6b88d06ce20d8ae5a. This update preserves the code-first admin/account/review work already deployed.

## Behaviour

- Default homepage and collection order is claimed businesses first, followed by unclaimed records. Both groups are A–Z with a stable listing-ID tie-break. Owner UUIDs do not determine placement.
- Area, service, urgency, publication and trust filters are applied before ranking. An out-of-area claimed business cannot outrank an in-area unclaimed business because it is excluded from the local result set.
- Pagination spans the full claimed/unclaimed partition rather than reordering only the first fetched page. Explicit name and Google-rating sorts remain available and keep their stated meaning.
- Visitors select their area; a functional cookie remembers only that coarse area for 30 days. An explicit URL area overrides it, including an explicit All KZN choice. No GPS/IP inference or location permission request is added.
- Durban North and Ballito / North Coast remain separate from PMB. North Coast URL aliases point only to the existing Ballito-labelled records, not invented coverage of every coastal suburb.
- Related-profile suggestions use the same exact known stored area, exclude the current profile before limiting, prioritise claims, and do not broaden to other regions when local supply is empty. Broad Other KZN/unknown area records do not produce location claims.
- Clearing job filters retains the selected area. Only an explicit All KZN choice widens the search. Unsupported area strings do not quietly return the whole province.
- Ranking and privacy explanations updated. Database records, credentials, reviews, WhatsApp message wording, and monetisation are unchanged.
